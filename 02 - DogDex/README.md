# 🐶 DogDex

Meu primeiro projeto desenvolvido com React durante minha jornada **Do Zero ao Desenvolvimento**.

O objetivo deste projeto é praticar conceitos fundamentais do desenvolvimento Front-End, como componentes, gerenciamento de estado, consumo de APIs, manipulação de dados e organização de código.

---

# 🎯 Objetivo

Criar uma aplicação capaz de pesquisar raças de cães utilizando uma API pública e exibir informações relevantes para o usuário.

---

# 🚀 Tecnologias

- React
- Vite
- JavaScript (ES6+)
- CSS3
- Fetch API

---

# ✅ Funcionalidades da V1

- Buscar uma raça pelo nome
- Exibir imagem da raça
- Exibir nome
- Exibir peso
- Exibir altura
- Tratar erros de pesquisa

---

# 📚 Conceitos Praticados

- Componentes React
- JSX
- Props
- useState
- Eventos
- Consumo de APIs
- Async/Await
- Manipulação de JSON
- Organização de código
